# ADR 0003: Single Source of Truth Print Snapshot Generator

## Status
Accepted

## Context
Print outputs (Thermal receipt, A4 HTML, Reprint) previously recalculated item line totals, subtotals, and taxes independently. This created visual discrepancies between displayed saved invoices and printed receipts.

## Decision
All printing mechanisms must consume a pre-formatted, immutable print snapshot generated by `invoiceEngine.generatePrintSnapshot(invoice, storeInfo)`. Printing templates are strictly prohibited from recalculating financial numbers.

## Consequences
- **Positive:** Absolute 1:1 match between saved invoice data and printed receipts across all printer targets.
- **Positive:** Disables currency suffix text (`ج.م`/`جنيه`) consistently across all templates.
